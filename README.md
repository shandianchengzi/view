# 看台 · 场馆座位与视角

GitHub Pages: https://shandianchengzi.github.io/view/

静态、无需登录的场馆座位参考工具。基于用户提供的视野 Live HAR 快照（2026-10-23）中的场馆数据及浏览器组件进行本地适配，另补齐七份公开静态模型文件。保留 122 个场馆、场次和来源说明。

## 功能

- 搜索并切换场馆、场次、分区和可用舞台布局。
- 可点击与缩放的二维分区示意图。
- 座位视角滚轮／双指缩放时实时显示 35mm 等效焦距，可复制并到 [取景器](https://shandianchengzi.github.io/camera-translator/) 换算手机倍数。
- 3D 场馆全景与座位视角；不支持 WebGL 时原组件可降级为兼容渲染。
- 前后、左右相对位置、站坐姿及屋顶切换。
- 浏览器本地保存多个位置，复制可复现位置的链接。
- 场馆、场次资料及参考座位图来源链接。

所有运行脚本与场馆模型同仓库托管，无需请求原站 API。周深鸟巢参考座位图已本地保存，其余参考图片保留外部来源，查看时需要联网。首次完整加载并缓存完成后可离线使用核心功能。未包含登录、照片社区、投稿或原站统计功能。

## 数据边界

本项目不是现场实测或官方售票座位图。保留原数据的示意、估算和来源说明，不应通过相对位置滑块推算真实排座。

特别是周深 2026-09-25/26/27 鸟巢场次，原始数据注明“专属舞台与内场尚未建模”。3D 为通用参考，不代表该场专属舞台和实际遮挡。

## 本地运行与部署

使用任意静态 HTTP 服务器打开仓库根目录，例如 `python -m http.server 8000`。不需要安装依赖或构建。

GitHub Pages 由 `.github/workflows/pages.yml` 部署。仅打包页面、脚本、样式与 assets，排除开发配置。

## 焦距显示

沿用 camera-translator 的 35mm 等效焦距约定（手机倍数 = 目标焦距 / 基准镜头焦距）。该工具没有 FOV 反算代码，本项目补充了投影换算：`f = hypot(36,24) / (2 * hypot(aspect,1) * tan(verticalFov / 2))`，角度换算成弧度后计算。使用当前 3D 画幅比例及相机实际垂直视角，按对角线等效；调整窗口后同步更新。数值取整显示为估算值。

仅“我的视角”的变焦对应焦距变化；3D 全景滚轮改变观察距离，二维图缩放也不对应镜头焦距。手机主摄参数、倍数与像素预算请在取景器中换算，不设统一的手机 1× 焦距。
